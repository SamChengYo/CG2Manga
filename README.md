# CG2Manga

把多張有順序的圖片交給視覺 LLM（H200 Ollama／Qwen）理解角色與劇情，自動加上漫畫式的字幕（對話框、內心話、大喊、旁白、時間字卡、狀聲詞），再讓使用者手動微調並匯出 PNG。

## 執行

```powershell
cargo run --release
```

首次使用請到「⚙ 設定」分頁填入 **API 網址**、**模型名稱**（預設空白）與 **API 金鑰**（或先設定環境變數 `H200_API_KEY`）。圖片一律以原圖原尺寸送出，程式會依檔案大小自動分批（每批約 128 MiB 內）。

## 使用流程

1. **① 角色**：新增角色、填名字與描述（個性、口吻、關係），並加入參考圖。
2. **② 故事**：填風格（可點預設標籤）、劇情方向、文字量、閱讀方向、直排或橫排。
3. **③ 頁面**：加入圖片或資料夾（也可以直接拖進視窗），用 ◀ ▶ 調整順序。
4. **④ 生成與編輯**：
   - 「全部生成」：第一階段分批看圖（含角色參考圖），辨認角色、臉部位置與空白區域；第二階段依照全部畫面分析撰寫前後連貫的台詞。
   - 「只重寫全部台詞」：沿用看圖結果，換風格後重寫（較快）。
   - 「重寫本頁台詞」：只重寫目前這頁，前後文會一起提供給模型。
   - 編輯：拖曳框移動位置，拖曳黃點調整尾巴，雙擊空白處新增，按 Delete 刪除，PageUp／PageDown 換頁。
   - 生成完成後會**自動輸出**到來源旁邊的「名稱(翻譯)」資料夾：選資料夾 `C:\圖\故事A` 會輸出到 `C:\圖\故事A(翻譯)`；選圖片則用第一張圖片的檔名。修改後可按「重新輸出」。
5. 「儲存專案」會存成 `.cg2m.json`，之後可以繼續編輯。

## 程式結構

| 檔案 | 內容 |
|---|---|
| `src/model.rs` | 專案、角色、頁面、對話框與設定的資料結構 |
| `src/llm.rs` | 呼叫 API、讀取原圖並轉成 Base64、依大小分批、兩階段提示詞、容錯的 JSON 解析 |
| `src/layout.rs` | 自動擺放對話框，考慮說話者臉部位置、避開臉、空白區域與閱讀順序 |
| `src/render.rs` | 用 tiny-skia 搭配 ab_glyph 繪製各種框型與直排或橫排中文。預覽和匯出共用這份程式 |
| `src/app.rs` | egui 介面 |
